# Poliklinika Bandić — web stranica

Statična stranica, bez builda.

## Struktura
- `index.html` — cijela stranica
- `support.js` — runtime koji stranica treba (ne brisati)
- `img/` — fotografije

## Objava na GitHub Pages
1. Napravi novi repozitorij i uploadaj sav sadržaj ovog foldera u root.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. Za minut-dva stranica je na `https://<korisnik>.github.io/<repo>/`.

Lokalno: otvori `index.html` u browseru (ili `npx serve .`).
